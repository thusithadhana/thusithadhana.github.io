# Technical Innovation Portfolio — GitHub Pages

## Upload
1. Extract this ZIP on your computer.
2. Upload `index.html`, the entire `assets/` folder, and this README to the root of `thusithadhana.github.io`.
3. Commit the changes to the `main` branch.
4. In Settings → Pages, choose Deploy from a branch → `main` → `/(root)`.

Keep the folder structure intact. The page expects the `assets/` directory to sit next to `index.html`. The Canon TechSuite Pro demo video has been optimized for web playback and GitHub Pages.

The business-impact calculator is an illustrative model. Its outputs are not measured results or guaranteed savings.
