# Technical Excellence Award Portfolio — GitHub Pages

A responsive static portfolio website prepared for Thusitha Dhananjaya, Metropolitan Excellence Awards 2026, Category 04: Technical Excellence Award.

## Files
- `index.html` — portfolio site (responsive, no build tools required)
- `assets/` — supplied TechSuite screenshots, redacted Smartboard previews, award photos, award ceremony video and training photographs
- `evidence/` — nomination application and supporting evidence report files

## Before publishing
This package is configured as a **public** website template, but the supplied evidence documents and screenshots may contain internal/company information. Review all files and obtain written Metropolitan approval before publishing them publicly. In particular:
- The raw Google Sheets link is not embedded; add an approved anonymized viewer link in the peer-feedback section only after checking permissions.
- Smartboard dashboard previews are intentionally blurred. Do not replace them with unredacted screenshots unless the company authorizes publication.
- Remove `evidence/` documents or any other files that are not approved for public distribution.
- Replace bracketed placeholders with approved URLs or remove the placeholders.
- Do not publish customer data, passwords, private respondent details, proprietary source code, or confidential financial/operational records.

## Publish on GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username). Choose **Public** if using GitHub Free for this setup. You may add a README, but it is optional.
3. On the repository page, choose **Add file → Upload files**.
4. Upload the contents of this folder, not the parent folder itself. Ensure `index.html` is in the repository root, and the `assets/` and `evidence/` folders sit beside it.
5. Enter a commit message such as `Add technical excellence portfolio` and click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
8. Choose branch `main` and folder `/ (root)`, then click **Save**.
9. Wait a few minutes. The site should appear at `https://YOUR-USERNAME.github.io/`.
10. Open the published URL in a private/incognito browser window to confirm that the page and any approved document links work.

Official instructions: https://docs.github.com/en/pages/quickstart and https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Edit the page
Edit `index.html` directly in GitHub or locally with a text editor. Search for `[PLACEHOLDER` to find fields that need attention. Keep the local asset paths relative (for example, `assets/techsuite-login.png`). After committing changes, GitHub Pages will rebuild the site.
