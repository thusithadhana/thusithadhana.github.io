# Technical Excellence Award Portfolio — GitHub Pages

## Upload
Upload the contents of this folder to the root of the repository `thusithadhana.github.io`.
Keep `index.html` in the repository root and preserve the `assets/` folder structure.

## Enable GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Select branch `main` and folder `/(root)`.
4. Save and wait for publishing.

Website: https://thusithadhana.github.io/

## Contents
- `index.html` — responsive portfolio homepage with scroll reveal and hover animations.
- `assets/` — supplied screenshots, training photos, award photos and award ceremony video.

Internal nomination and supporting evidence documents are intentionally not included in this public website package. They are provided separately for internal submission.

Before publishing, ensure you have permission to publicly share all photos, videos, company-related screenshots and identifiable participants. Do not add confidential data or private survey responses.
